# Explorador XP — alpha.46

Versão: `0.1.0-alpha.46` (`versionCode 46`)

## Tela principal

- removido o cartão grande de armazenamento da página inicial;
- espaço livre e percentual usado passam para a barra inferior;
- o indicador de armazenamento é clicável e abre a análise completa;
- a capacidade acompanha o volume atual (armazenamento interno ou cartão SD) sem executar a varredura pesada automaticamente.

## Barra de ferramentas

- adicionados atalhos diretos **Atualizar** e **Novo**;
- **Novo** oferece **Nova pasta** e **Novo arquivo**;
- o layout dos atalhos foi compactado para manter as ações na mesma faixa.

## Seleção

- ações diretas: **Copiar**, **Mover**, **Renomear**, **Compartilhar**, **ZIP**, **Excluir** e **Mais**;
- **Mais** fica reservado para ações menos frequentes e opções específicas de ZIP.

## Novo arquivo

- criação de arquivo vazio com validação de nome;
- arquivos de texto compatíveis abrem diretamente no editor interno após a criação.

A assinatura permanente e o `applicationId` continuam inalterados.
