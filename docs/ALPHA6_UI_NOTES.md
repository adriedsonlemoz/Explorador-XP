# Alpha 6 — interface XP e armazenamento

Referência visual: mockup aprovado com barra de título XP, menu clássico, toolbar e endereço.

Mudanças:
- botão Início na toolbar;
- seletor de armazenamento no Endereço;
- detecção de cartão SD via volumes externos do Android;
- card de capacidade apenas na página inicial do armazenamento interno;
- navegação segura por raiz de volume;
- atualização dos ícones principais para a nova família visual XP.
