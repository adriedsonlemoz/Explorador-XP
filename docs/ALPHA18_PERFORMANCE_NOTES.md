# Alpha 18 — Macrobenchmark + Baseline Profile

Versão: `0.1.0-alpha.18` (`versionCode 18`)

Esta entrega adiciona o primeiro sistema formal de medição e otimização AOT do Explorador XP. O perfil inicial já acompanha o app, enquanto `:baselineprofile` pode gerar regras baseadas em execução real. O Macrobenchmark compara inicialização e scroll com e sem perfil e produz relatórios consultáveis.

Nenhuma mudança visual foi feita.
