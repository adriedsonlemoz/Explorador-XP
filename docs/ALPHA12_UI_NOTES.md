# Explorador XP — alpha.12

## Launcher Android

- Fundo grafite separado do foreground.
- Foreground contém somente a pasta dourada com transparência ao redor.
- A arte não possui máscara arredondada própria; o formato final é aplicado pelo Android.
- Pasta ampliada e centralizada para corrigir o aspecto pequeno observado na tela “Acesso a todos os arquivos”.
- `ic_launcher` e `ic_launcher_round` usam Adaptive Icon no Android 8+.
- Android 13+ recebe `monochrome` para ícones temáticos.
- Mipmaps legados mantidos consistentes como fallback visual.
