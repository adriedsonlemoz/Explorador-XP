# Alpha 3 — ajustes visuais aplicados

- Barra superior compacta com Voltar, Subir e Exibir antes de “Explorador”.
- Busca e menu permanecem no lado direito.
- Local atual em barra compacta no estilo de endereço do Windows Explorer.
- Controle “Ocultos” permite mostrar/ocultar arquivos iniciados por ponto ou marcados como ocultos; estado fica salvo.
- Itens em lista e grade exibem data e horário de criação. Quando o sistema de arquivos não fornece criação, usa a última modificação como fallback.
- Navegação inferior: Arquivos / Downloads / Favoritos.
- Downloads abre diretamente `/Download` do armazenamento interno.
- Indicador de armazenamento: ícone alinhado à barra; espaço usado dentro do trecho verde; espaço livre dentro do trecho livre; total fora da barra, à direita.
- Interface em modo imersivo de tela inteira; barras do sistema reaparecem temporariamente por gesto.
