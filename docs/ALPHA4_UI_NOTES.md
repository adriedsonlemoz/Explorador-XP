# Alpha 4 — Cabeçalho Explorer XP

A alpha.4 substitui o cabeçalho móvel simplificado por uma estrutura visual baseada diretamente no Windows Explorer do XP:

1. barra de título azul;
2. menu Arquivo/Editar/Exibir/Favoritos/Ferramentas/Ajuda;
3. toolbar com Voltar, Avançar, Subir, Pesquisar, Pastas e Exibir;
4. barra de endereço com localização atual;
5. medidor de armazenamento compacto mantido logo abaixo.

Os ícones usados continuam sendo os assets XP já incorporados ao projeto. A opção de arquivos ocultos foi movida para Exibir para reduzir altura do topo.
